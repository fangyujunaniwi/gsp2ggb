# gsp-conv — 几何画板 (.gsp) ⇄ GeoGebra (.ggb)

中文 | [English](README_EN.md)

把**几何画板**（The Geometer's Sketchpad）的 `.gsp` 文件与 **GeoGebra** 的 `.ggb` 文件互相转换，
并尽量保留**动态构造关系**——中点、交点、垂线/平行线、角平分线、平移/旋转/缩放/反射、路径上的点、
距离与各种测量等，都会转成 GeoGebra 的*命令*，而不只是把坐标搬过去。所以在 GeoGebra 里拖动一个
自由点，整套图形仍会跟着动。

## 它适合做什么
- 把老师/教材里的几何画板课件搬到 GeoGebra 继续编辑或演示。
- 把 GeoGebra 作品带回几何画板。
- 批量转换整个文件夹的课件。

## 主要特性
- **双向转换**：`.gsp → .ggb` 与 `.ggb → .gsp`。
- **保留构造关系**：尽量发射成 `Midpoint`、`Intersect`、`Rotate`、`Reflect` 之类的 GeoGebra 命令，
  而不是一堆死坐标。
- **保留动态交互**：线段/多边形/圆上的点仍可拖动、可动画；「隐藏 / 显示 / 动画 / 移动 / 同时」等
  动作按钮会转成 GeoGebra 按钮脚本。
- **零依赖**：只用 Node.js，不需要 `npm install`。
- **命令行 + 图形终端界面（TUI）**：喜欢敲命令或点选都行。
- **出错不猜**：无法可靠识别的对象会**跳过并给出告警**（连带的依赖对象也会一并移除），
  以保证输出文件一定能正常打开，而不是产生错误图形。

## 环境要求
- **Node.js 18 或更高**（已在 Node 24 上测试）。除此之外**不需要安装任何东西**。
- 转换本身跨平台；文档里的截图/打开校对脚本仅 Windows 需要。

没装 Node？到 <https://nodejs.org/> 下载 LTS 版安装即可。

## 快速开始

```bat
:: 单个文件：.gsp -> .ggb（输出与输入同名，扩展名不同）
node bin\cli.js input.gsp

:: 指定输出文件
node bin\cli.js input.gsp -o out.ggb

:: 反向：.ggb -> .gsp
node bin\cli.js input.ggb -o out.gsp
```

转换完成后，用 GeoGebra 打开生成的 `.ggb` 即可。（转换**不需要**先装 GeoGebra。）

## 常用命令

```bat
:: 批量转换整个文件夹里的所有 .gsp/.ggb；--outdir 省略时输出到 <文件夹>\converted
node bin\cli.js "D:\我的课件" --outdir "D:\输出"

:: 强制方向（默认按扩展名自动判断）
node bin\cli.js input.gsp --to gsp

:: 安静模式，只输出结果
node bin\cli.js input.gsp -q

:: 让输出便于程序处理（机器可读）
node bin\cli.js input.gsp --json

:: 自检：不需要任何素材，验证程序本身是否正常
node test\smoke.js
```

其他 CLI 参数：`-o/--out`、`--outdir`、`--to ggb|gsp`、`-q/--quiet`、`--json`、`-h`。
自检成功会打印 `SMOKE PASSED`。

如果用 npm 脚本，也可以：`npm run convert -- input.gsp -o out.ggb`、`npm run selftest`、`npm run stats`。

## 交互式界面（TUI）

不想记命令就用它：

```bat
node bin\tui.js
:: 或
npm run tui
```

在界面里可以：浏览并选择 `.gsp`/`.ggb` 文件或整个文件夹、切换转换方向与输出位置、运行转换并查看
报告。按 `w` 看告警明细，按 `o` 在资源管理器中打开输出目录。它同时兼容管道/CI 等非交互环境
（会自动退化成逐行编号菜单），所以也能写进脚本。

## 转换效果怎么看
- **打开生成的 `.ggb`**：点、线、圆、多边形、测量值等应正确显示；拖动自由点能带动图形。
- **看不到图形？** 转换不会自动调整视图范围。在 GeoGebra 里缩放一下，或用“视图”菜单里的
  “显示全部对象”即可找到图形。
- **有对象没转过来？** 看命令行的告警（或用 TUI 按 `w`）。这是有意为之：识别不了的对象宁可
  跳过，也不猜一个可能是错的几何，从而保证文件能打开、其余部分正确。

## 支持与不转换（简要）
**支持**：点、线段、直线、圆、多边形、中点、各类交点、垂线/平行线、角平分线、平移/旋转/缩放/
反射、路径上的点、坐标轴与单位点、函数及其图像上的点、度量（长度/距离/角/比值/面积/周长/半径等）、
文本标注、动作按钮（隐藏/显示/动画/移动/同时）。

**有意不转换**（跳过并告警）：Sketchpad 的**迭代 / 列表 / 自定义工具**族，以及少数按钮类型
（如“滚动”）；依赖它们的对象会一并跳过。

逐类型的完整清单与说明见 [`TYPE_TABLE.md`](TYPE_TABLE.md) 与 [`Tech_Details.md`](Tech_Details.md)。

## 常见问题

**Q：为什么有些对象没有转换？**
A：无法可靠确定其含义的对象会被跳过并给出告警，同时移除依赖它们的对象，以确保输出能正常打开。
详见告警信息。

**Q：GeoGebra 里“数字”好像变成了滑块或图形？**
A：几何画板的测量读数（长度、角度等）被有意设为**不在绘图区显示**，它们仍会出现在“代数区”。
而作为可调参数的“自由数字”则保留为可拖动滑块——这是动态关系的一部分。

**Q：圆上的点位置和原来不完全一样？**
A：当初始位置无法从文件可靠解出时，我们只保证该点**仍在圆上且可动画**，初始位置交给 GeoGebra
选取，而不是猜一个可能错的位置。

**Q：需要联网吗？**
A：不需要。转换完全在本机进行，不上传任何文件。
