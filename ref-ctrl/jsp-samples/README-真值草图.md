# 需要你制作的“标记变换”真值草图（用于确认 t21/t29/t33）

这些草图必须用**注册版**几何画板制作（预览版不能导出 `.htm`）。每个草图请**另存为两种格式**，
文件名相同、扩展名不同，放进 `ref-ctrl/jsp-samples/`：

- `文件(F) → 另存为` → 保存类型 **几何画板 5 (*.gsp)**
- 再次 `文件(F) → 另存为` → 保存类型 **JavaSketchpad (*.htm)**

> 原理：`.gsp` 里有我们要辨型的二进制对象；`.htm` 里是**明文**构造表达式，两份的**对象顺序都是构造顺序**，
> 可逐条对齐，从而给 `t21/t29/t33` 定性（`node tools\jspextract.js <x.htm> --json`）。

请尽量**每次只用一个变换**、对象少而清晰、并**给点起单字母名**（A、B、C、O…）。建议做下面 6 个：

| # | 文件名建议 | 构造步骤 |
|---|---|---|
| 1 | `mark_center_rotate_fixed.gsp/.htm` | 画点 O 与点 P；**选中 O → 变换→标记中心**；只选 P → **变换→旋转→输入 90°**。得到 P′。 |
| 2 | `mark_angle_rotate.gsp/.htm` | 画 ∠ABC（3 点）；**依次选 A、B、C → 变换→标记角度**；画点 O、点 P；**标记 O 为中心**；只选 P → **变换→旋转→（默认用标记角度）**。得到 P′。 |
| 3 | `measure_angle_rotate.gsp/.htm` | 用“度量→角度”量出 ∠ABC 得到数值；画点 O、P；只选 P → **变换→旋转**，角度处**点选那个测量值**。得到 P′。 |
| 4 | `mark_ratio_dilate.gsp/.htm` | 画线段 AB、CD；**依次选 AB、CD → 变换→标记比值**；画点 O、点 P；**标记 O 为中心**；只选 P → **变换→缩放**（用标记比）。得到 P′。 |
| 5 | `mark_vector_translate.gsp/.htm` | 画 A、B；**选 A、B → 变换→标记向量**；画点 P；只选 P → **变换→平移**。得到 P′。（对照，t16 已知） |
| 6 | `mark_distance_translate.gsp/.htm` | 用“度量→距离”量出 AB 的**长度值**并选中它，再配一个方向（或直接试 **变换→平移** 里用标记距离/标记角）。目的是复现 `MarkedAngleMarkedDistance` / `FixedAngleMarkedDistance`。 |
