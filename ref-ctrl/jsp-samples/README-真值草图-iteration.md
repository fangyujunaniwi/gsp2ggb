# 需要你制作的「迭代」真值草图（用于定性 t89/t77/t88/t75/t32/t10）

## 为什么需要
`t89/t77/t88/t75/t32`（合计约 2.4 万，是当前最大的缺口）是 GSP 的**迭代 / 自定义工具**族。
已看清的结构（以 `点的迭代(蚂蚁).gsp` 为例）：

- `t10` ＝ 迭代的**变量槽**（包住被迭代的对象，如圆）；
- `t48` ＝ 迭代**次数**（标签常是「点总个数」）；
- `t89` ＝ 迭代的**映射**：父 `[次数, 各参与对象…, 变量]`，带 `tag 2314`；
- `t77` ＝ 迭代的**一步**：父 `[变量, 映射]`；`t88` ＝ 迭代产出的点；
- `t32/t75` ＝ 自定义工具 / 迭代实例。

要把它映射成 GeoGebra 的 `Iteration` / `Sequence` / `Zip`，必须知道**映射体**是怎么由变量构造的、
迭代从什么初值开始、以及不同类型（点/线段/数值/多边形）的差异。

> **好消息**：JavaSketchpad 会把迭代**内联展开**成逐步的对象写进 `.htm`——所以 `.htm` 正好是
> 「迭代展开后长什么样」的明文真值，可与 `.gsp` 的 `t89/t77` 逐条对照。

## 请制作（**注册版**，每个都另存 `.gsp` + `.htm`，放进 `ref-ctrl/jsp-samples/`）

### 草图 1 — `iter_point_rotate.gsp/.htm`
1. 画两点 `O`、`P`。
2. **只选中 `P`** → `变换(T) → 迭代…`（或 `构造(C) → 迭代`）。
3. 在迭代对话框里：把 `O` 指定为**旋转中心**、选**旋转**、角度 **60°**；迭代次数设 **5**。
   确定，得到一串迭代点。
   （对话框若要求先「标记中心/角度」，就先用 `变换(T)→标记中心` 标记 O、`标记角度` 标记 60°，再迭代。）

### 草图 2 — `iter_point_translate.gsp/.htm`
同上，但改成**平移**（例如沿某个向量平移）迭代 5 次。

### 草图 3 — `iter_number_plus1.gsp/.htm`
1. 建一个自由数字 `n`（用「数据(N) → 新建参数」或「计算」），初值 1。
2. 选中 `n` → `变换(T) → 迭代…`，让规则为 `n+1`（在对话框里对 `n` 做 `+1`），迭代 **5** 次。

### 草图 4 — `iter_segment_rotate.gsp/.htm`
1. 画圆心 `O` 与一条线段 `AB`。
2. 只选线段 `AB` → `变换(T) → 迭代…`：绕 `O` **旋转 30°**，迭代 **6** 次。
