# 需要你制作的「迭代」真值草图（用于定性 t89/t77/t88/t75/t32/t10）

> 依据 `Sketchpad Help\几何画板迭代教程.pdf` 更正了操作步骤。
> **核心**：几何画板迭代 = `x_{k+1} = f(x_k)`。先在画板里**手工做出第一个迭代象** `f(原象)`，
> 再在 `变换→迭代` 对话框里把「**原象**」与「**初象**(=f(原象))」配对；
> **规则 f 由「原象→初象」的构造隐式给出**，**次数**在「显示」菜单里设。
> 只有一个初象 = 单映射迭代；多个 = 多映射迭代。

## 为什么需要
`t89/t77/t88/t75/t32`（约 2.4 万，最大缺口）就是这套迭代。语料里只存了压缩后的迭代对象，
「原象/初象/次数」是**隐式**的；要映射成 GeoGebra 的 `Iteration`/`IterationList`，必须对照明文真值。
**JavaSketchpad 会把迭代内联展开**写进 `.htm` —— 正是我需要的明文对照。每个草图**另存 `.gsp` + `.htm`**，
放进 `ref-ctrl/jsp-samples/`。

## 请制作（注册版）

### 草图 1 — `iter_point_rotate.gsp/.htm`（单映射·点旋转）
1. 画点 `O`（旋转中心）、点 `P`（**原象**）。
2. 双击 `O` 标记中心；选中 `P` → `变换(T)→旋转(R)` → 固定角度 **60°** → 得 **`P′`**（**初象**）。
3. **只选中 `P`** → `变换(T)→迭代(I)`。在迭代对话框里点「**初象**」下方的方框，再点 **`P′`**；
   点 `显示(D)→增加迭代` 把次数调到 **5**；按「**迭代**」按钮。
4. 另存 `iter_point_rotate.gsp`，再另存为 `.htm`。

### 草图 2 — `iter_point_translate.gsp/.htm`（单映射·点平移）
同上，但第 2 步改成：`A`、`B` 两点 → 选中 `A`、`B` → `变换(T)→标记向量`；选中 `P` → `变换(T)→平移`
→ 得 `P′`；再按第 3 步迭代。

### 草图 3 — `iter_number_plus1.gsp/.htm`（数值迭代，对应例1 等差数列）
1. `数据(N)→新建参数` 建参数 **`n`=1**（**原象**，不能有父对象）。
2. `数据(N)→计算` 算 **`n+1`**（**初象**）。
3. 选中 **`n`** → `变换(T)→迭代(I)` → 初象框点 **`n+1`** → `显示→增加迭代` 设为 **5** → 迭代。
4. 另存。

### 草图 4 — `iter_segment_rotate.gsp/.htm`（带子对象的迭代）
1. 画点 `O`（中心）、`A`、`B`；连线段 **`AB`**（**原象**）。
2. 双击 `O` 标记中心；选中 **`AB`** → `变换(T)→旋转(R)` → 固定角度 **30°** → 得线段 **`A′B′`**（**初象**）。
   （注意：原象的子对象会一并参与迭代。）
3. 只选 **`AB`** → `变换(T)→迭代(I)` → 初象框点 **`A′B′`** → 次数 **6** → 迭代。
4. 另存。
