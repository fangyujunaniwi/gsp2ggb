# 需要你制作的「弧」真值草图（用于确认 t79/t80/t81）

## 为什么需要
JavaSketchpad **不导出弧**（`Sketch.java` 里没有 `Arc` 构造），所以 `.htm` 对弧无效。
而 `t79/t80/t81` 的父结构在语料里**是混合的**（t79 多为 `[圆,点,点]`，也有 `[点,点,点]`；
t80/t81 多为 `[圆心,点,点]` 或 `[变换点,变换点,变换点]`），且**方向约定未验证**——
盲目映射会画出错误的弧。需要一份**构造已知**的最小草图，用**渲染**定死：

1. 到底哪种选择顺序产生 `t79`、哪种产生 `t80/t81`（即父对象是「圆」还是「圆心」还是「三个点」）；
2. 弧从哪个点到哪个点、走**顺时针还是逆时针**。

## 请制作（**只需 `.gsp`**，不必导出 `.htm`）

### 草图 1 — `arc_circle_PQ.gsp`
1. 画两点 `O`、`A`。
2. 选中 `O`、`A` → 菜单 `构造(C) → 圆上的点`… 里选 **“以圆心和圆上的点画圆”**，得到圆 `c`。
3. 用「点」工具在圆 `c` 的**圆周上**再取两点 `P`、`Q`。
4. **依次选中：圆 `c` → 点 `P` → 点 `Q`** → 菜单 `构造(C) → 圆上的弧`。得到弧。
5. 另存为 `arc_circle_PQ.gsp`。
