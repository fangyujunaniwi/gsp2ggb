# 需要你制作的「定角/标记距离平移」真值草图（用于确认 t24）

`t24`（语料 4,355 条，当前 0 发射）已由**语料结构 + `jsp5.jar` 反编译**定性为 Translator 族的
**`FixedAngleMarkedDistance`（定角 + 标记距离平移）**：

- 记录：**2 个父对象 + 4 个 double**，参数形如 `(-sinθ, cosθ, θ, 0)`（θ = 固定角）。
- 第 2 个父对象在语料里**绝大多数是 `t48`（计算/度量值）**，即「标记距离」。
- 语义（反编译 `FixedAngleMarkedDistance.prepareTransformer`）：
  `deltaX = 标记距离值 × cos(θ)`、`deltaY = −标记距离值 × sin(θ)`（文件 y 向下）。

还差两点必须用**可控真值**确认，才敢落地：

1. **父角色**：第 1 父 = 原像、第 2 父 = 标记距离，是否确实如此（会不会反序）。
2. **单位换算**：`标记距离值` 在文件坐标里是「点坐标单位」还是「长度单位（cm）」——
   这决定发射到 GeoGebra 时要不要乘/除坐标比例。

## 请这样制作

用**注册版**几何画板。每个草图都**另存为两种格式**（同名、不同扩展名）放进 `ref-ctrl/jsp-samples/`：

- `文件(F) → 另存为` → 保存类型 **几何画板 5 (\*.gsp)**
- 再次 `文件(F) → 另存为` → 保存类型 **JavaSketchpad (\*.htm)**

> 要求：对象尽量少、点尽量用单字母名、**每个草图只做一种平移**，结果点命名如 `P'`。

### 草图 1 — `translate_fixedangle0_markeddist.gsp/.htm`（主目标，应产出 t24）
1. 用「线段」工具画 A、B 两点，连成线段 AB。
2. 选中线段 AB → 菜单 `度量(M) → 长度`，得到一个长度值。
3. 选中这个长度值 → 菜单 `变换(T) → 标记距离`。
4. 用「点」工具画一个自由点 **P**。
5. 选中 P → 菜单 `变换(T) → 平移…`，在对话框中选择：
   - 距离：**标记的**
   - 方向/角度：**固定**，填 **0 度**
   确定，得到 **P'**。

### 草图 2 — `translate_fixedangle90_markeddist.gsp/.htm`
与草图 1 完全相同，只把第 5 步的**固定角度改成 90 度**。
> 草图 1、2 一起就能看出方向是「y 向上还是向下」，以及位移量是否等于 AB 的长度值。

### 草图 3 — `translate_markedangle_fixeddist.gsp/.htm`（对照，应产出另一个 2 父类型）
1. 画 ∠ABC（三点 A、B、C，B 为顶点）；**依次选 A、B、C** → `变换(T) → 标记角度`。
2. 画自由点 **P**。
3. 选中 P → `变换(T) → 平移…`：距离 = **固定**（填 2 厘米），方向/角度 = **标记的**。确定 → **P'**。

### 草图 4 — `translate_markedangle_markeddist.gsp/.htm`（对照，应产出 3 父类型）
1. 先按草图 1 的第 1–3 步标记一个距离。
2. 再画一个角 ∠DEF（D、E、F，E 为顶点）并 `变换(T) → 标记角度`。
3. 画自由点 **P** → `变换(T) → 平移…`：距离 = **标记的**，方向/角度 = **标记的**。确定 → **P'**。
