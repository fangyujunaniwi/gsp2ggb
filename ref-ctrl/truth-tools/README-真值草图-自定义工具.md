# 需要你制作的「自定义工具」真值草图（用于定性/落地 t32）

> 目标：确认 **自定义工具实例 `t32` 的父表如何对应工具的输入/输出**，以及**工具定义在 .gsp 里的编码**。
> 我已在 `Support Files\Example Tools.gsp` 看到定义的样子（`tag 1100` 工具名 + `tag 1204` 输入输出序 +
> `tag 9007` 说明），但**没有「使用处」的实例**做对照——所以需要你在同一文档里**既定义、又使用**这个工具。

## 通用步骤（每个草图都一样）

1. 用**本机装好的 GSP5**（`D:\Sketchpad5\GSP5chs.exe`）**新建**一个文档（不要用旧文件另存）。
2. 在主画面里画出该工具的**输入对象**与**输出对象**（见各草图）。
3. 只选中要作为**输入**的对象 + 作为**输出**的对象，用菜单
   **「工具(T) → 新建工具(C)...」**（或「自定义工具 → 新建工具」）建立一个工具，起个英文名（如 `Mid2`）。
4. **同一文档里再使用这个工具至少 2 次**（换不同的输入对象），确认画板里真的生成了工具的输出。
5. **另存为 `.gsp`**，放进本目录（文件名见各草图）。
6. 若存工具时画板问「是否存入工具文件夹」，**也存一份**，并把那个文件一并放进本目录。

> 只做哪个都行：**草图 A 最重要**（最简），B 用来确认“多输出/多输入”的编码，C 用来确认“递归/迭代型工具”。

---

## 草图 A —— `ct_midpoint.gsp`（2 输入 / 1 输出，点）

1. 画点 `A`、`B`；连线段 `AB`；作 `AB` 的中点 `M`。
2. 选中 `A`、`B`（输入）与 `M`（输出），**新建工具**，命名 `Mid2`。
3. 再画点 `C`、`D`，用工具 `Mid2` 作用到 `C`、`D` → 应得到 `C D` 的中点 `N`。
4. 再画点 `E`、`F`，再用一次 → 得到 `E F` 的中点。
5. 另存 `ct_midpoint.gsp`。

## 草图 B —— `ct_circumcircle.gsp`（3 输入 / 2 输出，点+圆）

1. 画点 `A`、`B`、`C`；作它们的外接圆（两条中垂线交点 `O` + 圆 `O`）。
2. 选中 `A`、`B`、`C`（输入）与 `O`、圆（输出），**新建工具**，命名 `Circ3`。
3. 再画三角形 `D`、`E`、`F`，用工具 → 得到外心与外接圆；再做一组。
4. 另存 `ct_circumcircle.gsp`。

## 草图 C —— `ct_fractal.gsp`（递归型，点）

> 这是语料里的大头（`兔年吉祥` 一类分形）。能做出最好，做不出可跳过。

1. 画点 `P`、`Q` 与一条线段/参数（代表规则），做一个“由两点算出下一点”的构造，输出点 `R`。
2. 新建工具，命名 `Step2`。
3. **用工具递归地造出两三层**（像分形那样一层层套用）。
4. 另存 `ct_fractal.gsp`。
